** Open dataset
	import delimited vit_E.csv, clear case(preserve)

* Generate high vitamin E variable
	gen h_vitE = vitE>12

* Reminder of OR
	gen partial_r = 0
	gen partial_s = 0
	bysort set : replace partial_r = 1 if h_vitE[1] == 1 & h_vitE[2] == 0
	bysort set : replace partial_s = 1 if h_vitE[1] == 0 & h_vitE[2] == 1
	count if partial_r==1 & case==1
	count if partial_s==1 & case==1
	
	dis 41 / 54

	clogit case vitE , group(set) or nolog

	* Note that this returns a very similar test statistic and p-value as

*** Question 4

* Use an interaction with vit E to investigate changing effect over "time"
	clogit case h_vitE##time , group(set) or
** Note that we cannot estimate the effects of "time" (as the time variable takes 
** the same value for each person within a matched set).
    
	** Test the interaction term 
	est store C
	lrtest A C
		
	** Estimate the odds ratios (and CIs) by "time" using lincom
		lincom 1.h_vitE+1.h_vitE#2.time, eform
		lincom 1.h_vitE+1.h_vitE#3.time, eform

** We could also look use continuous vitamin E
	clogit case vitE c.vitE#i.time , group(set) or
	est store D

	lrtest B D
	* Some evidence that the association with vitamin E levels changes over time.

	** Estimate the odds ratios (and CIs) by "time" using lincom
		lincom vitE+vitE#2.time, eform
		lincom vitE+vitE#3.time, eform

*** Question 7

** a. Matching variables only
	logit case age parity i.education, or

** b. Variables of interest only
	logit case i.spontaneous, or

** c. Matched variables and variables of interest
	logit case i.spontaneous age parity i.education, or nolog

** Note that the estimated odds ratios for the matching variables are no longer 
** close to 1. This illustrates that we must always adjust for matching variables 
** either explicitlty (as here) or implicity using conditional logistic regression 	

** Comparing standard errors from the two valid approaches
	logit case i.spontaneous age parity i.education, nolog
	clogit case i.spontaneous, group(stratum) nolog

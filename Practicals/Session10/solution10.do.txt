*Question 8 - cross-validation
drop svar
splitsample, gen(svar, replace) nsplit(10) rseed(723442)

postfile auccv svar auc using auccv, replace

forvalues i=1(1)10 {
	*fit model using all observations except i'th fold
	logit chd sbp tobacco ldl i.famhist obesity alcohol age if svar!=`i'
	*estimate AUC on i'th fold
	lroc if svar==`i', nograph
	*post AUC to file
	post auccv (`i') (r(area))
}

postclose auccv

use auccv, clear
summ auc
/*The 10-fold cross validation estimate of AUC is 0.778, slightly lower than the 0.782 we obtained in question 4 when we fitted the model and estimated the AUC using the entire sample. One thing to note is that this cross-validation value is an estimate - if we change the seed, and obtain different partitions of the data, we will obtain different estimates. Moreover, the actual quantity being estimated changes with the number of folds used. See Section 7.10.1 of the Elements of Statistical Learning book if you are interested to read further.*/
